# Task ID: T-MED-12 (기관명 필터 — 조사 붙은 케이스 구제)

### 배경

T-MED-11에서 추가한 `_INSTITUTION_SUFFIX_PATTERN`이 문자열 "끝"에만 앵커링(`$`)돼 있어서, 실제
배포된 CLOVA 키로 재현한 결과 "특정 기관의 연구 결과에 따른 것으로 본 약국의 의견과는 다를 수
있습니다"라는 처방전 문구에서 "약국의"(약국+조사 "의")가 필터를 통과함. 한국어 조사는 띄어쓰기
없이 명사에 바로 붙기 때문에, 끝 앵커 방식으로는 "필독약국"처럼 조사 없는 케이스만 잡히고
"약국의"/"약국은" 같은 케이스는 새어나감. 그 결과 T-MED-11 이전 버그로 이미 DB에 남아있던 쓰레기
레코드("SAMPLE*약국", `AUTO_E89FC2A23C`)와 계속 유사도 매칭됨.

### 참조

- 관련 코드: `app/services/medication_service.py` (`_INSTITUTION_SUFFIX_PATTERN`)
- 선행 작업: T-MED-11
- 관련 이슈: #120

### 범위

- **포함**: `_INSTITUTION_SUFFIX_PATTERN`을 끝 앵커(`$`) 대신 "텍스트 어디에든 포함되면 제외"로
  완화. 이전 버그로 이미 생성된 쓰레기 레코드(`AUTO_E89FC2A23C`, "SAMPLE*약국") DB 삭제(스케줄
  미연결 확인됨, 코드 변경과 별개로 운영 DB에서 직접 처리).
- **제외**: 조사 목록을 명시적으로 나열해 더 정교하게 구분하는 방식(과설계 — "포함" 방식으로 충분).
