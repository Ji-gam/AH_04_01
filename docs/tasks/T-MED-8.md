# Task ID: T-MED-8 (제조사명 대괄호 동반 시 약품명 후보 인식)

### 배경

T-MED-7(webp 변환) 수정 후 실제 배포된 CLOVA 키 + 실제 처방전 사진으로 검증한 결과, 6개 약품 중
5개는 정상 인식됐으나 "노스판패취10㎍/h [한국먼디파마]"만 후보에서 빠지는 것을 확인함. 원인은
`_DRUG_FORM_SUFFIX_PATTERN`(`app/services/medication_service.py`)이 문자열 끝(`$`)에 앵커돼 있던 것 —
실제 처방전은 브랜드명+용량 뒤에 제조사명 대괄호가 같은 줄에 인쇄되는데, 제조사명이 한글이라 문자열이
한글로 끝나버려 앵커가 깨졌다. mg/ml 단위가 있는 나머지 5개 약은 `_DOSAGE_PATTERN.search()`(끝 앵커
없음)로 우연히 통과했을 뿐이었다.

### 참조

- 관련 코드: `app/services/medication_service.py` (`_DRUG_FORM_SUFFIX_PATTERN`, `_looks_like_drug_name`)
- 선행 작업: T-MED-7
- 관련 이슈/PR: #103, #104

### 범위

- **포함**: 제형 접미사 판별을 문자열 끝 앵커(`$`) 대신 "접미사 바로 뒤에 한글이 이어지지 않으면
  인정"하는 부정 전방탐색으로 변경. "환자정보"/"서방정" 같은 기존 오탐 방지 케이스는 계속 걸러지는지
  회귀 테스트로 확인.
- **제외**: OCR 필드 분리 방식 자체 개선(CLOVA 응답 구조 변경 요청 등), 다른 제형 접미사 추가 발굴 —
  필요 시 별도 태스크.
