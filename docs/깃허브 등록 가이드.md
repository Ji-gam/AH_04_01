# 깃허브 등록 가이드 (백엔드/프론트엔드 폴더 구조)

> `remedi_backend_v3.zip`, `remedi_frontend_v3.zip`를 깃허브에 올릴 때 참고하는 문서입니다.

---

## 1. 저장소 구조 (모노레포 방식)

깃허브 저장소 하나 안에 `backend/`, `frontend/` 폴더를 나란히 두는 방식을 추천합니다.

```
remedi/                    ← 깃허브 저장소 하나
├── backend/                ← remedi_backend_v3.zip 푼 내용 통째로
└── frontend/                ← remedi_frontend_v3.zip 푼 내용 통째로
```

---

## 2. ⚠️ 폴더 이름이 겹쳐 보이는 부분 (정상입니다)

`remedi_backend_v3.zip`을 풀면 안에 이렇게 생겼습니다.

```
remedi_backend_v3/
├── main.py
├── backend/          ← 파이썬 코드 패키지 (이름이 "backend"임)
│   ├── core/
│   ├── domains/
│   └── utils/
└── requirements.txt
```

이걸 깃허브 저장소의 `backend/` 폴더 안에 그대로 넣으면 아래처럼 됩니다.

```
remedi/
└── backend/              ← 프로젝트 상위 폴더 (내가 정하는 이름)
    ├── main.py
    ├── backend/          ← 코드 패키지 (원래부터 이 이름, 바꾸면 안 됨)
    │   ├── core/
    │   └── domains/
    └── requirements.txt
```

**"backend" 안에 또 "backend"가 있는 것처럼 보이지만, 이건 버그가 아니라 원래 그런 구조입니다.**

- 코드 안에서 `from backend.domains.user.model import User` 처럼 **"backend"라는 이름을 그대로 import 경로에 사용**하고 있습니다.
- 그래서 **안쪽 `backend/` 패키지 폴더 이름은 절대 바꾸면 안 됩니다** (바꾸면 모든 import가 깨집니다).
- 반면 **바깥쪽 상위 폴더 이름**(위 예시의 `remedi/backend/`)은 원하는 대로 바꿔도 상관없습니다 (`server/` 등으로 바꿔도 무방).

> 📌 한 줄 요약: **`main.py`와 같은 레벨에 있는 안쪽 `backend/` 패키지 폴더 이름만 절대 건드리지 않으면** 나머지는 자유롭게 배치해도 됩니다.

---

## 3. "클론받으면 바로 끝"이 아니에요

`.gitignore`에 걸려 있는 아래 항목들은 **일부러 깃허브에 안 올라갑니다.**

- `.env` (비밀번호 등 민감정보 포함이라 원래 공유 파일에 올리면 안 됨)
- `node_modules/` (용량이 크고, `npm install`로 언제든 재생성 가능)
- `__pycache__/`
- `*.db` (로컬 테스트용 SQLite 파일)

그래서 저장소를 새로 클론받은 사람은 아래 과정을 **각자 한 번씩** 해줘야 실제로 돌아갑니다.

### 백엔드
```bash
cd backend
pip install -r requirements.txt
cp .env.sample .env      # 복사 후 .env 열어서 실제 MySQL 접속정보 등으로 수정
```

### 프론트엔드
```bash
cd frontend
npm install
cp .env.example .env
```

이건 잘못된 게 아니라 **의도된 동작**입니다. 비밀번호가 든 `.env`와 용량이 큰 `node_modules`를 굳이 깃허브에 올릴 필요가 없기 때문입니다.

---

## 4. 요약 체크리스트

- [ ] `remedi/backend/`, `remedi/frontend/` 형태로 나란히 배치
- [ ] 안쪽 `backend/` 패키지 폴더(core, domains, utils가 들어있는 그 폴더) 이름은 그대로 유지
- [ ] `.env`, `node_modules`, `__pycache__`, `*.db`는 커밋하지 않기 (이미 `.gitignore`에 등록되어 있음)
- [ ] 클론 받은 사람은 각자 `pip install -r requirements.txt` / `npm install` + `.env` 파일 생성 필요
