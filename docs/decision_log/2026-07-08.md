# 2026-07-08 — 하네스 문서 2차 정리: AGENTS.md 단일 진입점화

## 배경

`CLAUDE.md`(경계) + `AGENT_PLAYBOOK.md`(실행) + `.agents/AGENTS.md`+`CONVENTIONS.md`+`TASK_CONTRACT_TEMPLATE.md`
(Task Contract 체계) + `.antigravity/rules/`(Antigravity 툴용 사본)로 규칙 문서가 흩어져 있었다. 조사 결과:

- `.antigravity/rules/AGENTS.md`는 Tortoise ORM·`features/` 구조 등 이미 폐기된 스택을 기준으로 한 낡은 스냅샷이었다(`.agents/AGENTS.md`가 최신 버전).
- `.agents/AGENTS.md`가 정의하는 Task Contract(T-ID별 allowed/forbidden 경로) + `docs/tasks/_active.json` claim 파일은,
  실제로 `agent-Antigravity`(T-MED-1)와 `agent-Claude`(T-LLM-3)가 동시에 다른 도메인을 작업 중임을 기록하는 데
  쓰이고 있는 살아있는 메커니즘이었다 — 폐기 대상이 아니라 새 구조에 편입해야 했다.
- `.agents/CONVENTIONS.md`에는 API 응답 envelope 포맷, 에러코드 체계, DB 네이밍 규칙 등 다른 어떤 문서에도 없는 고유 내용이 있었다.

## 결정

1. **`AGENTS.md`(루트, 신규)를 단일 진입점(SSOT)으로 삼는다.** 약 150라인으로 압축해 "매번 읽어야 할 핵심 계약"만
   담고, 자주 안 쓰는 상세 절차는 관심사별 위성 문서로 분리했다:
   - `docs/SESSION_START.md` — Drill-Me 절차 + STOP 프로토콜
   - `docs/DEV_WORKFLOW.md` — TDD 구현순서, 로컬 실행환경, 검증 커맨드, 커밋/PR·스택형 PR 머지 절차
   - `docs/TROUBLESHOOTING.md` — 자주 만나는 문제 A~I
2. **`CLAUDE.md`는 "AGENTS.md를 읽어라"만 남기는 리다이렉트 스텁으로 슬림화**했다. 조사 결과 `CLAUDE.md` 본문에
   Claude Code 툴 자체에 고유한 내용은 없었다 — 전부 범용 프로젝트 규칙이었기 때문에 남길 예외가 없었다.
3. **`.agents/` 폴더를 통째로 삭제**했다. `AGENTS.md`(Task Contract 핵심 5원칙 + 디렉토리 소유권)는 새 루트
   `AGENTS.md`로, `CONVENTIONS.md`(코드 스타일/API 응답/DB 네이밍/공용 상수)는 `docs/CODING_RULES.md` 10~13번으로,
   `TASK_CONTRACT_TEMPLATE.md`는 실제 사용 위치인 `docs/tasks/TASK_CONTRACT_TEMPLATE.md`로 각각 이관했다.
4. **`.antigravity/rules/AGENTS.md`를 "../../AGENTS.md를 읽어라" 한 줄 스텁으로 교체**하고, 중복이던
   `.antigravity/rules/TASK_CONTRACT_TEMPLATE.md`는 삭제했다 (canonical 사본은 `docs/tasks/`에 하나만 유지).
5. **`docs/decision_log.md`를 `docs/decision_log/` 폴더로 날짜별 분할**했다. 기존 내용은 changelog 상 전부
   2026-07-07 하루에 속해 있어 `docs/decision_log/2026-07-07.md` 파일 하나로 소급 이관했고, 앞으로는
   `YYYY-MM-DD.md` 파일당 하루 컨벤션을 따른다 (`docs/decision_log/README.md` 참고).
6. **`docs/plan/PRD_ReMedi_v1.1.md`/`TRD_ReMedi_v1.1.md`의 내부 헤더 버전을 파일명과 일치시켰다** (`v1.0` →
   `v1.1`) — 내용 본문은 건드리지 않고 표기 불일치만 정정.
7. `docs/FRONTEND_UI_GUIDE_v1.0.md`가 1차 정리(2026-07-07) 때 이미 폐기된 `FRONTEND_ARCHITECTURE.md`를 여전히
   참조하고 있던 것을 확인해 `docs/CODING_RULES.md` 3번으로 참조를 갱신했다(내용 자체는 변경 없음).
