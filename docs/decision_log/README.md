# decision_log/ — 아키텍처 결정 로그 (날짜별)

## 컨벤션

- 파일당 하루: `YYYY-MM-DD.md`. 그날 있었던 결정/사고 경위/배경 설명을 그 파일에 추가한다.
- 같은 날 여러 건이면 그 날짜 파일 안에 `##` 섹션으로 나눠 이어붙인다.
- 기존 결정을 뒤집는 경우, 예전 파일 내용을 지우지 않고 새 날짜 파일에 "무엇을 왜 뒤집었는지"를 기록한다 (과거 파일은 그 시점의 기록으로 그대로 둔다).
- 이 로그는 "왜 이렇게 됐는지" 배경 설명 전용이다. "지금 지켜야 할 규칙"은 `AGENTS.md`/`docs/CODING_RULES.md`/`docs/CONTRIBUTING.md`에 있다 — 이 로그를 규칙 원본으로 쓰지 않는다.
