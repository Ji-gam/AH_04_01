## ⚠️ 먼저 확인 부탁 — 현재 덱의 사실관계 오류 1건

**19p(⑪ RAG 아키텍처)와 20p(⑫ 문제 진단 및 재설계)가 `QueryClassification`을 현재 구조로 서술하고 있는데, 이 컴포넌트는 지금 코드에 없습니다.**

- 19p 파이프라인 다이어그램에 `QueryClassification / 2축 구조화 분류` 박스가 있음
- 20p 재설계 결과가 `QueryClassification 2축 구조화 분류로 전환`으로 서술됨
- 실제: 코드 전수 검색 결과 **0건**. 파이프라인 통합(T-LLM-7-3-2) 때 제거됐고, 질환 판별은 규칙 기반 `disease_query_resolver.resolve_diseases()`가 맡습니다.

**수정 방향**
- 20p(⑫)는 **"당시의 진단·재설계 과정"**으로 시제만 분명히 하면 그대로 사실입니다 (문장 손댈 필요 거의 없음).
- 19p(⑪) 다이어그램 박스는 현재 구현대로 **`disease_query_resolver` 규칙 기반 질환 판별**로 바꿔야 합니다.

심사위원이 코드에서 확인하려 하면 바로 드러나는 항목이라 우선순위를 높게 봤습니다.
